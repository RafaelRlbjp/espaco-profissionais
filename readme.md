# 🌿 Espaço Essentia

Site institucional desenvolvido para um espaço de atendimento integrado nas áreas de **Psicologia e Nutrição**.

O projeto tem como objetivo apresentar as profissionais, seus serviços e facilitar o contato e agendamento diretamente pelo WhatsApp.

## ✨ Funcionalidades

- Página inicial responsiva
- Apresentação das profissionais
- Área dedicada à Psicologia
- Área dedicada à Nutrição
- Apresentação dos serviços
- Agendamento pelo WhatsApp
- WhatsApp individual para cada profissional
- Área de localização e contato
- Menu responsivo para dispositivos móveis

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
